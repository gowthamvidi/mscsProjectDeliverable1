# Advanced Operating Systems – Custom Python Shell

**Author:** Raghav Gurram, Vikram Reddy Tekula, Shiva Gowtham Kumar Vidiyala  
**Language:** Python  
**Project:** Advanced Operating Systems – Deliverables 1–4

## Project Overview

This project implements a custom Python-based shell demonstrating fundamental operating system concepts, including process management, CPU scheduling, memory management, synchronization, command piping, and security.

## Deliverables

- **Deliverable 1 – Basic Shell:** Implements built-in commands, foreground/background processes, and job control.
- **Deliverable 2 – Process Scheduling:** Implements Round-Robin and preemptive Priority-Based scheduling.
- **Deliverable 3 – Memory Management:** Implements paging, FIFO/LRU page replacement, and producer-consumer synchronization using mutexes and semaphores.
- **Deliverable 4 – Integration & Security:** Integrates previous deliverables with command piping, user authentication, and simulated role-based file permissions.

## Technologies Used

Python, OS System Calls, Multithreading, Mutexes, Semaphores, Scheduling Algorithms, and Role-Based Access Control (RBAC).

## How to Run

Requirements: Python 3.10+ and Linux, macOS, or WSL.

### Deliverable 1 – Basic Shell
cd Deliverable1
python3 deliverable1_shell.py

### Deliverable 2 – Process Scheduling
cd Deliverable2
python3 myshell_deliverable2.py

### Deliverable 3 – Memory Management and Synchronization
cd Deliverable3
python3 myshell

### Deliverable 4 – Integration and Security
cd Deliverable4
python3 myshell_deliverable4.py
```

Keep `scheduler.py`, `memory_sync.py`, and `security_d4.py` in the same directory.

## Features

- Built-in shell commands and job management
- Round-Robin and Priority-Based scheduling
- FIFO and LRU memory management
- Producer-consumer synchronization
- Multi-command piping
- User authentication and simulated file permissions

## Conclusion

This project demonstrates the integration of essential operating system concepts into a modular Python shell for educational purposes.
